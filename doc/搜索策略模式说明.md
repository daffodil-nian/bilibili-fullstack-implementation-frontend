# 搜索结果页：策略模式拆分说明

## 目录

```text
searchResult/
  searchResult.vue              # 只负责：搜索框、Tab、排序、调度策略
  style.scss
  strategies/
    types.ts                    # SearchStrategy 接口
    index.ts                    # Tab → 策略注册表
    userStrategy.ts             # 用户：searchType=2，读 userList
    articleStrategy.ts          # 专栏：searchType=6，读 articleList
    videoStrategy.ts            # 视频类工厂：VIDEO/ANIME/LIVE
    unsupportedStrategy.ts      # 综合/影视等暂未开放
  components/
    UserResultList.vue
    ArticleResultList.vue
    VideoResultList.vue
```

## 怎么扩展一种新类型

1. 新建 `xxxStrategy.ts`（实现 `fetch` + `sortTabs`）
2. 新建 `XxxResultList.vue`（只管展示）
3. 在 `strategies/index.ts` 的 `strategyMap` 挂一行

主页面 `searchResult.vue` **不用改业务 if/else**。

## 请求约定

统一：`POST /api/search/all`

| Tab | searchType | 解析字段 |
|-----|------------|----------|
| 用户 | 2 | `userList` |
| 专栏 | 6 | `articleList` |
| 视频/番剧/直播 | 1/4/5 | `videoList`（后端待补） |
| 综合/影视 | null | 不请求 |
