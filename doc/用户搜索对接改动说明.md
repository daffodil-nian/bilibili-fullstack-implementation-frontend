# 用户搜索前后端对接改动说明

目标：顶栏搜索进入结果页后，切换到「用户」Tab 可调用后端并展示用户搜索结果；**不改原有样式文件**，其它 Tab 行为保持空结果。

---

## 一、前端（`bilibiliCopywriting-frontend`）

### 1. `src/services/urls.ts`

| 改动 | 说明 |
|------|------|
| 新增 `searchAll: '/api/search/all'` | 搜索接口地址 |

### 2. `src/services/api.ts`

| 改动 | 说明 |
|------|------|
| 新增类型 `SearchAllParams` / `SearchUserItem` / `SearchAllResult` | 对齐后端入参/出参 |
| 新增方法 `searchAll(params)` | `POST` 调搜索接口 |
| `default` 导出增加 `searchAll` | 方便统一引用 |

### 3. `src/views/search/searchResult/searchResult.vue`

| 改动 | 说明 |
|------|------|
| `handleSearch` | **仅当 Tab=用户(code=6)** 时调用 `searchAll`；`searchType` 传后端 `2`（USER） |
| 结果映射 | `userList` → 原有 `resultData` 的 `id/title/cover`，继续用原来的 `video-card` 结构展示（昵称→title，头像→cover） |
| `onMounted` | 从路由 `?keyword=` 读入关键词 |
| 模板 | 封面处增加可选 `<img>`（无头像仍显示「封面图」）；**未改 `style.scss`** |
| 其它 Tab | 仍返回空列表，不调后端 |

### 4. `src/components/layout/BilibiliHeader.vue`

| 改动 | 说明 |
|------|------|
| `goToSearch` | 打开 `/searchResult?keyword=编码后的关键词`（原先没带 keyword） |

**未改：** `style.scss`、路由表、其它业务页面、搜索页样式 class 名。

---

## 二、后端（为保证前端能调通，做了最小修复）

路径：`bilibilimock-background`

| 文件 | 改成什么 |
|------|----------|
| `controller/SearchController.java` | 路径改为 `/api/search`，方法改为 `POST /all`，去掉强制 `uid` |
| `UserContextInterceptor.java` | 白名单增加 `/api/search/**`（未登录也可搜） |
| `SearchTypeEnum.java` | static 填充 cache，避免 `of` 为 null |
| `SearchServiceImpl.java` | `doSearchUser` 改用 `req.getSortCode()` |
| `UserEsDao.java` | 去掉错误 `Pageable` 派生方法，只保留空 Repository（同步用） |

---

## 三、前后端字段对应

| 前端 | 后端 |
|------|------|
| Tab「用户」code=`6` | `searchType=2`（USER） |
| `sortCode` | `UserSortEnum`（0 默认等） |
| `keyword` / `currentNum` / `pageSize` | `SearchEsReq` 同名 |
| 展示 `nickname` → `title`，`avatar` → `cover` | `SearchVO.userList` |

请求示例：

```http
POST /api/search/all
Content-Type: application/json

{
  "keyword": "小宇",
  "searchType": 2,
  "sortCode": 0,
  "currentNum": 1,
  "pageSize": 20
}
```

---

## 四、如何自测

1. 后端、ES 启动；ES 中需已有用户文档（`userEsDao.save` / 全量同步），否则列表为空。  
2. 前端 `npm run dev`，代理 `/api` → `8080`。  
3. 顶栏输入关键词点搜索 → 新开结果页。  
4. 点「用户」Tab → 应出现昵称列表（有数据时）。  

---

## 五、刻意没动的

- `searchResult/style.scss` 及原有 CSS class  
- 综合/视频/番剧等其它 Tab 的真实接口  
- `defaultPage.vue`、搜索建议页等其它搜索相关页
