# Bilibili 设置页对齐 & 仿写功能差距

> 对照官方「个人中心 - 我的信息」截图与当前项目实现整理。  
> 本文档只说明**怎么改**，不直接改代码。

---

## 一、为什么你的设置页「只有侧栏、右边是白的」

根因不是样式，而是**没有「我的信息」表单内容**。

当前结构：

- `src/views/settingPage/index.vue` 右侧用 `<router-view />` 作为内容出口
- `src/router/index.ts` 只有 `/settingPage` 这一层，**没有子路由**
- 菜单 `key` 写的是 `/info`、`/avatar` 等，这些路由**不存在**，也没有对应组件

因此 `<router-view />` 永远是空的。

B 站截图里右边那一整块（昵称、用户名、签名、性别、生日、保存）是**真正的内容页**，当前项目还没做。

---

## 二、怎么改成接近 B 站「我的信息」

### 1. 补「我的信息」内容页（最关键）

新建例如：`src/views/settingPage/info.vue`，按 B 站表单实现：

| 字段 | 建议实现 |
|------|----------|
| 标题「我的信息」 | 左侧竖条 + 文案 |
| 昵称 | `a-input` + 右侧提示「修改一次昵称需要消耗6个硬币」 |
| 用户名 | 纯文本展示（一般不可改） |
| 我的签名 | `a-textarea` |
| 性别 | 三个按钮：男 / 女 / 保密，选中用 `#00a1d6` |
| 出生日期 | `a-date-picker` |
| 学校信息 | 灰色提示文案即可 |
| 保存 | 居中蓝色按钮 |

数据可先用 `getUserInfo()`（空间页已在用），保存时再调已有/待补的 API（昵称、签名等）。

### 2. 用嵌套路由把内容挂到右侧

在 `router/index.ts` 把设置页改成父路由 + 子路由，例如：

```ts
{
  path: '/settingPage',
  component: settingPage,
  redirect: '/settingPage/info',
  children: [
    { path: 'info', component: () => import('../views/settingPage/info.vue') },
    // 以后再加 avatar、security 等
  ]
}
```

菜单 `key` 改成和真实 path 一致，例如 `/settingPage/info`（`a-menu` 开了 `router`，点菜单才会跳进子页）。

### 3. 默认选中「我的信息」

- `selectedKeys` 初始设为 `['/settingPage/info']`
- 进入 `/settingPage` 时 `redirect` 到 `info`
- 这样打开就不会白屏

### 4. 视觉对齐（可选，但截图差很多）

按优先级改样式：

1. **外层**：`max-width` 约 `980~1100px` 居中；顶栏蓝底 `#00a1d6`，logo 左对齐（云朵/22娘装饰可后补）。
2. **侧栏**：白底 + 灰边；顶部加「个人中心」标题；当前项用**实心蓝底白字**（现在偏浅蓝底蓝字）。
3. **底部四项**：B 站是**外链 + 右侧 `>`**，不是 `a-sub-menu` 展开；可改成普通 `a-menu-item`，点击 `window.open` 到空间/钱包等。
4. **补菜单文案**（若要对齐旧版个人中心）：我的硬币、我的记录、实名认证、邀请注册、通知设置等；没有功能可先做占位页或禁用点击。

### 5. 图标报错先修掉

`settingPage/index.vue` 里用了 `CoinOutlined`、`MedalOutlined`，但 import 被注释了，页面可能报错。要么补 import，要么换成已有图标。

## 四、私信限流规则说明（产品口径）

用一张表把规则钉死，前后端都按这个实现：

| 双方关系 | 能否继续发消息 |
|----------|----------------|
| 互相关注 | 可以，无条数限制 |
| 未互关，且对方从未回复过你的私信 | 你对该会话**最多发 1 条** |
| 未互关，但对方已经回复过（双方都聊过） | 可以继续聊 |
| 对方把你拉黑 | 不能发 |

判定伪代码（后端）：

```text
if 互相关注:
  允许发送
else if 对方已回复过本会话 / 双方消息数都 > 0:
  允许发送
else if 自己在本会话已发送条数 == 0:
  允许发送（这是唯一的那一条）
else:
  拒绝：提示「对方回复前只能发送一条消息」
```

群聊与单聊限流相互独立：群内发言按群规则（成员身份、禁言），不套用「陌生人一条」限制。

## 五、一句话总结

- 设置页右边空白：缺「我的信息」子页面和子路由，先做 `info.vue` + 嵌套路由。
- 聊天能力：需要补**私信**；未互关时限制「最多一条，除非双方都聊过」；**群聊可以做，建议排在单聊之后**。
